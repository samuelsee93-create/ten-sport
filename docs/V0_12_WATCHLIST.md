# v0.12 Asset Watch List

- Assets can be starred into a private per-manager, per-league Watch List.
- Watch List entries persist in Supabase and follow the manager across devices.
- Assets can be filtered to "My Watch List only".
- The Watch column is sortable so watched assets can be brought to the top.
- Watch List is independent from Draft Favorites / Draft Queue and remains useful after the draft for waiver tracking.
